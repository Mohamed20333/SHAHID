# Contributing

This repository is primarily an academic term-project submission.

## Development

1. Use Node.js 22 or newer.
2. Copy `.env.example` to `.env` and adjust local values.
3. Install dependencies with `npm install`.
4. Run `npm run check`.
5. Run the demo with `npm run demo`.
6. Run the server with `npm start`.

Keep changes small, tested, and consistent with the documented architecture. Do not commit `.env`, database files, credentials, or real personal data.
