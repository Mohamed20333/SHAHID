# Data retention

SHAHID must use a documented institutional retention policy before collecting real student data.

Recommended categories:

- Raw BLE observations: shortest period needed for session review and security investigation.
- Cryptographic check-in records: institutional attendance retention period.
- Risk assessments: retain with the associated attendance record.
- Audit/security events: retain according to security/compliance policy.
- Private keys: never stored by the server.

The reference repository does not invent a universal legal retention period. Configure retention to the university's policy and applicable law before production deployment.
