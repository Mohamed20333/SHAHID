# Professor guide

1. Sign in with a provisioned professor account.
2. Open the Professor Control Center.
3. Select an owned section/session.
4. Start an attendance session.
5. Monitor the live attendance table.
6. Inspect evidence graph edges generated by the backend.
7. Review witness counts, evidence freshness and risk state.
8. End the session.
9. Use the resulting session records for institutional review.

The dashboard separates cryptographic check-in, BLE evidence, witness verification and risk assessment. A risk state is not an automatic disciplinary verdict.
